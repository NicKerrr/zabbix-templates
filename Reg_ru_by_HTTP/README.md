## Reg.ru Services Zabbix Template

---

# Шаблон Zabbix для мониторинга услуг Reg.ru

Шаблон использует Reg.ru API для получения списка активных услуг, автоматически обнаруживает домены и хостинги, а также создает элементы данных и триггеры для контроля сроков окончания услуг.

# Возможности

Шаблон собирает информацию о доменах и хостингах Reg.ru.

Мониторинг включает:

- автоматическое обнаружение доменов;
- автоматическое обнаружение услуг хостинга;
- дату создания домена;
- дату окончания домена;
- состояние домена;
- дату создания услуги хостинга;
- дату окончания услуги хостинга;
- состояние услуги хостинга;
- уведомления о скором окончании срока действия домена;
- уведомления о скором окончании срока действия хостинга.

# Триггеры

Для доменов и хостингов создаются триггеры:

- срок действия истекает через 60 дней;
- срок действия истекает через 30 дней;
- срок действия истекает через 7 дней.

Требования
- Zabbix 6.4 или выше
- Доступ Zabbix Server или Zabbix Proxy к https://api.reg.ru
- Учетная запись Reg.ru
- Доступ к Reg.ru API
- Логин и пароль/API password для выполнения API-запросов

# Макросы

После импорта шаблона необходимо задать макросы на уровне хоста или шаблона:

| Macro | Description |
|---|---|
| `{$USERNAME}` | Имя пользователя Reg.ru |
| `{$API.PASSWORD}	` | Пароль или API password пользователя Reg.ru |

# Используемый API

Шаблон использует endpoint Reg.ru API:

https://api.reg.ru/api/regru2/service/get_list

Для получения списка доменов используется параметр:

servtype=domain

Для получения списка услуг хостинга используется параметр:

servtype=srv_hosting_ispmgr

## Как это работает

Шаблон использует два основных HTTP agent item’а:

reg.raw.domain.data — получает список доменов;
reg.raw.hosting.data — получает список услуг хостинга.

Далее dependent discovery rules автоматически обнаруживают услуги из JSON-ответа API и создают dependent items для каждой найденной услуги.

Дата окончания услуги преобразуется из формата YYYY-MM-DD в Unix timestamp с помощью JavaScript preprocessing. Это позволяет использовать дату в триггерах Zabbix и сравнивать ее с текущим временем.

## Установка
- Скачайте файл шаблона из репозитория.
- В Zabbix откройте:
Data collection → Templates → Import
- Импортируйте файл шаблона.
- Создайте хост для мониторинга услуг Reg.ru.
- Привяжите к хосту шаблон:
Reg.ru by HTTP
- Укажите макросы {$USERNAME} и {$API.PASSWORD}.
- Убедитесь, что Zabbix Server или Zabbix Proxy имеет доступ к https://api.reg.ru.
- Дождитесь выполнения low-level discovery rules.

# Безопасность

Рекомендуется использовать отдельный API password или отдельную учетную запись Reg.ru с минимально необходимыми правами.

Не храните реальные логины, пароли или API password в репозитории.
